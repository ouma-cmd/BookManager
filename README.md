# 📚 BookManager - Gestion de Livres

## 📌 Description

BookManager est une application web de gestion et découverte de livres développée avec la stack **MERN (MongoDB, Express.js, React.js, Node.js)**.

L'objectif de l'application est de permettre aux utilisateurs de découvrir des livres, consulter leurs informations, lire des résumés et accéder à des liens externes pour acheter ou consulter le livre.

L'application contient deux espaces :

- 👨‍💼 **Administration**
  - Gestion des livres (CRUD)
  - Gestion des utilisateurs
  - Tableau de bord

- 👤 **Utilisateur**
  - Consultation des livres
  - Recherche et filtrage
  - Consultation des détails d'un livre
